4. CAMBIOS IMPLEMENTADOS (RESUMEN)
═════════════════════════════════════════════════════════════════════════════════

PROBLEMA:
  La detección anterior usaba tolerancia de ±20° (70-110°)
  Esto permitía FALSOS POSITIVOS (brazos casi derechos se detectaban como L)

SOLUCIÓN IMPLEMENTADA:
  Tolerancia de ±8° (82-98°) para detectar INTENCIÓN CLARA de formar 90°
  Esto requiere el PROFESOR para mayor precisión

CAMBIOS:
  1. src/config.py
     - ANGULO_CODO_ESTRICTO = (82, 98)    # ±8° (por defecto)
     - ANGULO_CODO_RELAJADO = (70, 110)   # ±20° (alternativa)

  2. src/geometry.py
     - es_postura_L(..., nivel="estricto")  # parámetro nuevo
     - Puede usar ESTRICTO o RELAJADO

  3. src/vision_pipeline.py
     - Usa explícitamente nivel="estricto"

RESULTADO:
  ✓ Detección más precisa
  ✓ Menos falsos positivos
  ✓ Sistema más responsive
  ✓ Flexible (puede cambiar a relajado si necesita)
