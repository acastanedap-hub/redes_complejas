            CAMBIOS EN DETECCIÓN DE POSTURA "L": TOLERANCIA ±8 GRADOS
═══════════════════════════════════════════════════════════════════════════════

DESCRIPCIÓN GENERAL:
Se ha implementado un sistema de DOS NIVELES de detección de la postura "L":
  1. ESTRICTO (±8 grados): Detecta la INTENCIÓN clara del usuario de formar 90°
  2. RELAJADO (±20 grados): Permite variabilidad durante confirmación

Esto mejora significativamente la precisión del reconocimiento de comandos.


═══════════════════════════════════════════════════════════════════════════════
JUSTIFICACIÓN TÉCNICA
═══════════════════════════════════════════════════════════════════════════════

ANTES (TOLERANCIA ±20°):
  ✗ Rango muy amplio: 70° a 110°
  ✗ Permite falsos positivos (brazos casi derechos parecían "L")
  ✗ No diferencia entre intención clara y variaciones naturales

DESPUÉS (TOLERANCIA ±8°):
  ✓ Rango estricto: 82° a 98° (INTENCIÓN clara de 90°)
  ✓ Detecta cuando el usuario INTENTA formar explícitamente los 90 grados
  ✓ Mayor precisión en el reconocimiento de comandos
  ✓ Mantiene compatibilidad con nivel relajado para confirmación

2. MODIFICACIÓN: src/geometry.py - Función es_postura_L()

ANTES:
    def es_postura_L(hombro, codo, muneca, ancho_ref):
        ang = angulo_articular(hombro, codo, muneca)
        brazo_horizontal = abs(hombro[1] - codo[1]) < config.TOL_HORIZONTAL * ancho_ref
        antebrazo_vertical = (
            abs(codo[0] - muneca[0]) < config.TOL_VERTICAL * ancho_ref
            and muneca[1] < codo[1]
        )
        dentro_rango = config.ANGULO_CODO_OBJ[0] <= ang <= config.ANGULO_CODO_OBJ[1]
        return dentro_rango and brazo_horizontal and antebrazo_vertical

DESPUÉS:
    def es_postura_L(hombro, codo, muneca, ancho_ref, nivel="estricto"):
        """
        ... documentación mejorada ...

        nivel : str
            "estricto": ±8 grados (detección de INTENCIÓN de formar 90°)
            "relajado": ±20 grados (permite variabilidad en confirmación)
        """
        ang = angulo_articular(hombro, codo, muneca)

        # Seleccionar rango según nivel de detección
        if nivel == "estricto":
            rango = config.ANGULO_CODO_ESTRICTO
        elif nivel == "relajado":
            rango = config.ANGULO_CODO_RELAJADO
        else:
            rango = config.ANGULO_CODO_OBJ

        brazo_horizontal = abs(hombro[1] - codo[1]) < config.TOL_HORIZONTAL * ancho_ref
        antebrazo_vertical = (
            abs(codo[0] - muneca[0]) < config.TOL_VERTICAL * ancho_ref
            and muneca[1] < codo[1]
        )
        dentro_rango = rango[0] <= ang <= rango[1]
        return dentro_rango and brazo_horizontal and antebrazo_vertical

CAMBIOS:
  ✓ Nuevo parámetro: nivel="estricto" (por defecto)
  ✓ Lógica para seleccionar el rango según nivel
  ✓ Documentación mejorada explicando ambos niveles
