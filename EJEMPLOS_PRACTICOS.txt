EJEMPLO 1: COMPARACIÓN DE ÁNGULOS
═════════════════════════════════════════════════════════════════════════════

USUARIO MIDE ÁNGULO DE 85° (intenta la L pero brazo no muy doblado)

    Medición real: ang = 85.3°

    NIVEL ESTRICTO (82-98°):
    ├─ 82° ≤ 85.3° ≤ 98°?
    ├─ ¿Es 85.3 ≥ 82? ✓ SÍ
    ├─ ¿Es 85.3 ≤ 98? ✓ SÍ
    └─ RESULTADO: ✓ DETECTADO (está dentro del rango)

    NIVEL RELAJADO (70-110°):
    ├─ 70° ≤ 85.3° ≤ 110°?
    ├─ ¿Es 85.3 ≥ 70? ✓ SÍ
    ├─ ¿Es 85.3 ≤ 110? ✓ SÍ
    └─ RESULTADO: ✓ DETECTADO (también está dentro)


USUARIO MIDE ÁNGULO DE 105° (brazo casi estirado)

    Medición real: ang = 105.7°

    NIVEL ESTRICTO (82-98°):
    ├─ 82° ≤ 105.7° ≤ 98°?
    ├─ ¿Es 105.7 ≥ 82? ✓ SÍ
    ├─ ¿Es 105.7 ≤ 98? ✗ NO (105.7 > 98)
    └─ RESULTADO: ✗ NO DETECTADO (fuera del rango)

    NIVEL RELAJADO (70-110°):
    ├─ 70° ≤ 105.7° ≤ 110°?
    ├─ ¿Es 105.7 ≥ 70? ✓ SÍ
    ├─ ¿Es 105.7 ≤ 110? ✓ SÍ

EJEMPLO 3: CÁLCULO MANUAL DE ÁNGULO
═════════════════════════════════════════════════════════════════════════════

Imagina que detectamos:
  • Hombro en posición (100, 100)
  • Codo en posición (150, 150)
  • Muñeca en posición (150, 80)

FUNCIÓN: angulo_articular(hombro, codo, muneca)

  1. Calcular vector v1 (hombro → codo):
     v1 = [150 - 100, 150 - 100] = [50, 50]

  2. Calcular vector v2 (muñeca → codo):
     v2 = [150 - 150, 80 - 150] = [0, -70]

  3. Producto punto:
     v1 · v2 = (50 × 0) + (50 × -70) = 0 - 3500 = -3500

  4. Normas:
     ||v1|| = √(50² + 50²) = √5000 ≈ 70.71
     ||v2|| = √(0² + (-70)²) = √4900 = 70

  5. Coseno del ángulo:
     cos(θ) = -3500 / (70.71 × 70) ≈ -0.707

  6. Ángulo:
     θ = arccos(-0.707) ≈ 135°

  INTERPRETACIÓN:
    Ángulo = 135° (brazo extendido, no es L)

    ESTRICTO: 82° ≤ 135° ≤ 98°? ✗ NO
    RELAJADO: 70° ≤ 135° ≤ 110°? ✗ NO

    RESULTADO: No se detecta como L (correcto)

EJEMPLO 5: COMPORTAMIENTO DEL CONTADOR (HISTÉRESIS)
═════════════════════════════════════════════════════════════════════════════

El contador mantiene histéresis: necesita 8 frames CONSECUTIVOS de L.

ESCENARIO: Usuario hace gestos confusos

┌────────┬──────────────┬──────────┬─────────────────┐
│ FRAME  │ ¿ES POSTURA? │ CONTADOR │ CONFIRMADO?     │
├────────┼──────────────┼──────────┼─────────────────┤
│ 1      │ ✓ Sí (90°)   │ 1        │ No (necesita 8) │
│ 2      │ ✓ Sí (91°)   │ 2        │ No              │
│ 3      │ ✓ Sí (90°)   │ 3        │ No              │
│ 4      │ ✗ No (75°)   │ 0        │ No ← SE REINICIA│
│ 5      │ ✗ No (110°)  │ 0        │ No              │
│ 6      │ ✓ Sí (88°)   │ 1        │ No ← COMIENZA DE NUEVO│
│ 7      │ ✓ Sí (92°)   │ 2        │ No              │
│ 8      │ ✓ Sí (90°)   │ 3        │ No              │
│ 9      │ ✓ Sí (89°)   │ 4        │ No              │
│ 10     │ ✓ Sí (91°)   │ 5        │ No              │
│ 11     │ ✓ Sí (90°)   │ 6        │ No              │
│ 12     │ ✓ Sí (88°)   │ 7        │ No              │
│ 13     │ ✓ Sí (90°)   │ 8        │ ✓ SÍ CONFIRMADO │
└────────┴──────────────┴──────────┴─────────────────┘

NOTA: En frame 4, aunque la L desaparece un momento, el contador se reinicia.
      Esto previene falsos positivos de gestos accidentales.

EJEMPLO 6: LLAMADA A LA FUNCIÓN EN CÓDIGO
═════════════════════════════════════════════════════════════════════════════

CÓDIGO PYTHON:

    from src.geometry import es_postura_L

    # Coordenadas reales del usuario (en píxeles)
    hombro = (100, 150)      # Hombro en x=100, y=150
    codo = (150, 200)        # Codo más abajo
    muneca = (150, 100)      # Muñeca más arriba (brazo levantado)
    ancho_ref = 200          # Ancho de hombros = 200px

    # NIVEL ESTRICTO (por defecto)
    resultado_estricto = es_postura_L(hombro, codo, muneca, ancho_ref)
    print(f"¿Es L (estricto)? {resultado_estricto}")  # True o False

    # NIVEL RELAJADO (explícito)
    resultado_relajado = es_postura_L(hombro, codo, muneca, ancho_ref,
                                      nivel="relajado")
    print(f"¿Es L (relajado)? {resultado_relajado}")  # True o False

POSIBLE SALIDA:
    ¿Es L (estricto)? True      (ángulo entre 82° y 98°)
    ¿Es L (relajado)? True      (ángulo entre 70° y 110°)

EJEMPLO 8: AJUSTE DE TOLERANCIA
═════════════════════════════════════════════════════════════════════════════════

Si descubres que la tolerancia ±8° es demasiado estricta:

OPCIÓN 1: Cambiar a ±10°
  ──────────────────────
  from src import config

  config.ANGULO_CODO_ESTRICTO = (80, 100)  # 90° ± 10°

  Ahora acepta: [80°, 100°]
  Antes era: [82°, 98°]
  Cambio: ±2° más tolerante en cada lado


OPCIÓN 2: Cambiar a ±5° (más estricto)
  ─────────────────────────────────────
  config.ANGULO_CODO_ESTRICTO = (85, 95)  # 90° ± 5°

  Ahora acepta: [85°, 95°]
  Antes era: [82°, 98°]
  Cambio: ±3° menos tolerante en cada lado


OPCIÓN 3: Crear niveles personalizados
  ────────────────────────────────────
  config.ANGULO_CODO_MUY_ESTRICTO = (88, 92)   # ±2°
  config.ANGULO_CODO_ESTRICTO = (82, 98)       # ±8°
  config.ANGULO_CODO_MODERADO = (80, 100)      # ±10°
  config.ANGULO_CODO_RELAJADO = (70, 110)      # ±20°
